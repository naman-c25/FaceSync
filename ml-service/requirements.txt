# Every version here was resolved for cp312 on linux — the Python the
# Dockerfile and CI both run — and checked against the local Windows 3.14
# development environment, where 53 of the 60 resolve identically and the
# remaining seven differ only by a patch release. So one pinned file serves
# both, rather than a lock that only the container can install.
#
# Pinned because they were not, and it broke: an unpinned resolution gave CI a
# newer Starlette than the laptop had, and the test client stopped importing.
# The deployed image builds from this file, so an unpinned rebuild the week of
# a demo can change what ships without a commit.
#
# To move a version deliberately, edit the direct dependency below and
# regenerate — see ml-service/README.md.
#
# NOTE: DeepFace/TensorFlow are deliberately NOT used. TensorFlow publishes no
# wheel for Python 3.14. InsightFace runs the same ArcFace architecture on
# ONNX Runtime instead: smaller, faster to start, and no TF dependency tree.
